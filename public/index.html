API REST de CazaTalentos

API para gestionar vacantes de empleo, empleadores y usuarios del portal. Todas las respuestas se devuelven en formato JSON.

/api/vacantes /api/empleadores /api/users

Vacantes

Método Ruta Descripción
GET /api/vacantes Lista todas las vacantes
GET /api/vacantes?modalidad=remoto&tipo=freelance Filtra por modalidad, tipo, categoria, salario_min y salario_max (combinables)
GET /api/vacantes/buscar?titulo=php Busca vacantes por título
GET /api/vacantes/:id Devuelve una vacante por su ID, con los datos del empleador
POST /api/vacantes Crea una vacante (cuerpo JSON)
PUT /api/vacantes/:id Actualiza una vacante (cuerpo JSON)
DELETE /api/vacantes/:id Elimina una vacante

Empleadores

Método Ruta Descripción
GET /api/empleadores Lista todos los empleadores
GET /api/empleadores?ubicacion=CABA Filtra por ubicacion
GET /api/empleadores/buscar?nombre=globant Busca empleadores por nombre
GET /api/empleadores/:id Devuelve un empleador por su ID
GET /api/empleadores/:id/vacantes Lista las vacantes publicadas por un empleador
POST /api/empleadores Crea un empleador (cuerpo JSON)
PUT /api/empleadores/:id Actualiza un empleador (cuerpo JSON)
DELETE /api/empleadores/:id Elimina un empleador

Usuarios

Método Ruta Descripción
GET /api/users Lista todos los usuarios
GET /api/users/:id Devuelve un usuario por su ID
POST /api/users Crea un usuario (cuerpo JSON)
PUT /api/users/:id Actualiza un usuario (cuerpo JSON)
DELETE /api/users/:id Elimina un usuario
